# /pc-epic-tuckin

1. Verify the assigned EPIC, repository and correlated task identity from the immutable brief.
2. Preserve the objective, constraints, plan, professional findings, evidence pointers and unresolved questions in the assigned task artifacts.
   Use [the EPIC body update pattern](../pc-epic/SKILL.md#epic-body-update-pattern) for authorized Issue edits.
3. Return the artifact pointers and pending evaluation work through the correlated task result to the owning Orchestrator.
   Resume only through its managed assignment.

**Done:** The Orchestrator has durable specialist findings and a concrete remaining scope; professional acceptance remains separate from human closure confirmation.
